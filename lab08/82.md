## TODO (1) — Inicjalizacja reprezentacji obiektu (`init`)

**Cel:** Przekształcenie obrazu wzorcowego `z` do tensora PyTorch i obliczenie map cech przez sieć szkieletową (backbone).

Obraz `z` zwrócony przez `crop_and_resize` ma kształt `[H, W, C]` (numpy array).
Sieć wymaga kształtu `[batch_size, C, H, W]`.

```python
# exemplar features
z = torch.from_numpy(z).to(self.device).permute(2, 0, 1).unsqueeze(0).float()
self.kernel = self.net.backbone(z)
```

Kroki:
- `torch.from_numpy(z)` — konwersja tablicy numpy do tensora
- `.to(self.device)` — przeniesienie na GPU (jeśli dostępne) lub CPU
- `.permute(2, 0, 1)` — zmiana kolejności wymiarów: `[H, W, C]` → `[C, H, W]`
- `.unsqueeze(0)` — dodanie wymiaru batcha: `[C, H, W]` → `[1, C, H, W]`
- `.float()` — konwersja do typu float32
- `self.net.backbone(z)` — obliczenie map cech; wynik zapisywany jako `self.kernel`

## TODO (2) — Obliczenie odpowiedzi sieci (`update`)

**Cel:** Obliczenie map cech dla ROI w każdej skali i przeprowadzenie korelacji wzajemnej z przechowywaną reprezentacją obiektu.

Tensor `x` jest już przygotowany wcześniej w metodzie jako `[num_scales, C, H, W]`.

```python
# responses
features = self.net.backbone(x)
responses = self.net.head(self.kernel, features)
responses = responses.squeeze(dim=1).cpu().numpy()
```

Kroki:
- `self.net.backbone(x)` — obliczenie map cech dla wszystkich skal jednocześnie (batch)
- `self.net.head(self.kernel, features)` — szybka korelacja wzajemna (fast cross-correlation) między reprezentacją obiektu a mapami cech ROI; wynik: `[num_scales, 1, H_resp, W_resp]`
- `.squeeze(dim=1)` — usunięcie zbędnego wymiaru kanału: `[num_scales, H_resp, W_resp]`
- `.cpu().numpy()` — przeniesienie na CPU i konwersja do numpy (wymagane przez dalsze operacje z OpenCV)

## TODO (3) — Główna pętla śledzenia (`track`)

**Cel:** Iteracja po klatkach sekwencji — inicjalizacja trackera na pierwszej klatce, aktualizacja lokalizacji na kolejnych.

```python
img = read_image(img_file)
if f == 0:
    self.init(img, box)
else:
    bbox = self.update(img)
    boxes[f] = bbox
    write_image(img, bbox, fig_n=f)
    if bbox[0] < 0 or bbox[1] < 0 or \
       bbox[0] > img.shape[1] or bbox[1] > img.shape[0]:
        print('Object lost. Aborting sequence tracking...')
        break
```

Kroki:
- `read_image(img_file)` — wczytanie klatki i konwersja BGR→RGB
- Klatka `f == 0`: wywołanie `self.init(img, box)` — inicjalizacja trackera z pierwszą ramką i prostokątem otaczającym z ground truth; `boxes[0] = box` ustawione jest już przed pętlą
- Kolejne klatki: wywołanie `self.update(img)` — zwraca nowy prostokąt otaczający `bbox`
- `write_image(img, bbox, fig_n=f)` — zapis klatki z narysowanym prostokątem do folderu `out/`
- Sprawdzenie granic: jeśli centrum obiektu wychodzi poza obraz, drukowany jest komunikat i śledzenie jest przerywane
